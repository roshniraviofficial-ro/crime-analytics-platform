CrimeSage AI

Conversational Crime Intelligence & Analytics Platform developed for Hack2Skill Datathon 2026

Features:
1. Crime record analysis
2. Risk Score prediction
3. Crime search functionality
4. Interactive dashboard
5. Conversational AI Support

Technologies Used:
1. Python
2. Streamlit
3. Pandas
4. Plotly
5. Machine Learning

Project Objective:
This project helps investigators and analysts identify crime patterns, repeat offenders, and risk levels using intelligent analytics and visualization.

How to Run?
1. Clone the repository
2. Install dependencies: pip install -r requirements.txt
3. Run the application: streamlit run app.py
